# terrible-cli
This is a simple implementation of an app that executes dialogue files for [TerribleDialogue](https://github.com/DavidRL77/TerribleDialogue).
Includes support for music, sound effects and colored text.

```
Usage:
  terrible-cli <files>... [options]

Arguments:
  <files>  The terrible dialogue files to run.

Options:
  -?, -h, --help  Show help and usage information
  --version       Show version information
```
